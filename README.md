# lab-course-inspired-projects

Welcome to my practical projects repository! Here, you will find applications developed based on concepts and ideas learned through personal studies and courses, but with **100% original implementations**.

## Objective

Instead of simply copying the code presented in courses, I use the project's proposal or scope as a starting point to create my own version.

This allows me to:

- Test and improve my programming logic
- Work with new technologies
- Improve my development skills

## How to Run the Projects

Each project has its own folder and its own `README.md` file containing specific installation and execution instructions.

Navigate to the folder of the project you are interested in to learn more.
