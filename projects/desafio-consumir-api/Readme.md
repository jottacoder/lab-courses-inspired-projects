# Desafio - Consumir API

> ### Aplicação com base no conceito do curso de [**Java-Consumindo APIs, gravando arquivos e lidando com erros.**] (oferecido por *[Jacqueline Oliveira e Paulo Silveira da Alura]*)

---

## Objetivo

- A ideia seria criar uma aplicação que consuma dados trazidos de uma API de endereços, transformá-los em objetos, gravar esses objetos em um arquivo e lidar com possíveis erros que possam ocorrer durante o processo.

---

## Tecnologias utilizadas

- Java 17
- biblioteca externa [Gson]

---

## Diferenciais da minha aplicação

- Arquitetura de código modularizada de forma diferente do curso, com pacotes separados por responsabilidade e classes com funções específicas, seguindo o princípio de responsabilidade única.
- Tratamento de erros mais robusto, com mensagens de erro detalhadas e logs para facilitar a identificação de problemas.
- Design de interface mais intuitivo e amigável para o usuário.

---

## Desafios e aprendizados

- Aprendi a consumir APIs RESTful em Java, utilizando bibliotecas como Gson para manipulação de JSON.
- Aprimorei minhas habilidades em tratamento de erros, implementando estratégias para lidar com exceções e mensagens de erro claras.
- Desenvolvi uma melhor compreensão de como modularizar o código, separando responsabilidades em diferentes pacotes e classes, o que resultou em um código um pouco mais organizado e fácil de entender.
- Aprendi a criar/modificar arquivos em Java, utilizando conceitos de serialização e desserialização de objetos para persistência de dados.
- Aprimorei minhas capacidades de resolução de problemas, enfrentando desafios relacionados à integração com APIs externas e à manipulação de dados em diferentes formatos.
